- Masalah apa yang ingin diselesaikan?
- Siapa yang paling terdampak?
- Proses manual apa yang ingin digantikan / diperbaiki?

Catatan:
- Fokus ke masalah, bukan fitur

## 2. Target Pengguna (Role)
Daftar peran pengguna:
- [ ] Admin
- [ ] Operator
- [ ] End User
- [ ] Lainnya: __________

Untuk tiap role:
- Apa yang mereka lihat?
- Apa yang mereka lakukan?
- Apa yang tidak boleh mereka lakukan?

## 3. Alur Kerja Utama (Flow)
Tuliskan alur dari awal sampai selesai:
- Masuk (login)
- Proses inti
- Output / hasil akhir

Contoh:
Login → Input Data → Validasi → Output → Selesai
